# Design input

This folder holds source material from Variant. Keep downloaded exports unchanged so they remain a reliable reference.

- Put the React or HTML download in `export/`. A ZIP file is preferred; do not unpack it unless asked.
- Put full-page PNG or JPG references in `screenshots/`. Include desktop and mobile when available.
- Put optional MP4 or MOV interaction recordings in `demos/` when motion, hover behavior, menus, or transitions matter.

If there are multiple Variant directions, use clear names such as `preferred`, `alternate-1`, and `alternate-2`, or state which one should be treated as final.
